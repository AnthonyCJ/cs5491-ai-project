## Instructor input and attribution

`vendor/dag_builder.py` is the unmodified CS5491 course reference implementation.
It supplies the two graphs, latency functions, fixed placements, scoring and
plotting interfaces. The project owner reported on 12 November 2026 that the
instructor had confirmed permission to publish the code. That report is the
permission basis; no independent written reply or additional open-source licence
is claimed. [Vendor attribution](../vendor/README.md) retains the course source.

The exact included Secure Hash Algorithm 256-bit (SHA-256) fingerprint is
`47a63fd1698da64731f8b9e77067f3ef7e0889534c4e7659bb7fc113ce97acee`.
The loader requires these bytes. A reader of the published candidate needs no
Canvas account to obtain this included file. The course Portable Document Format (PDF) file, original archive and
private source inventory are not redistributed. There is no external training dataset.

## Software and fonts

The [numerical lock](../requirements-s2.txt) and
[document lock](../requirements-docs-lock.txt) are separate. Version metadata,
compatible Windows wheel candidates and supplier hashes are recorded in
[dependency sources](dependency-sources.json). Installation and compatibility in a
fresh environment remain untested; follow the [installation guide](installation-unverified.md).

Times New Roman is a separately licensed system/document prerequisite. Its four
files are `times.ttf`, `timesbd.ttf`, `timesi.ttf` and `timesbi.ttf`.
[Microsoft lists supplying products and redistribution information](https://learn.microsoft.com/en-us/typography/font-list/times-new-roman).
Use a legally licensed copy; do not download arbitrary font mirrors or replace
it with a visually similar font. No font binaries, virtual environments or tool
binaries are included in this repository. Existing report PDFs retain their
original embedded fonts and version-specific checks.

Dependencies retain their supplier licences. [Third-party notices](../THIRD_PARTY_NOTICES.md)
identify their roles and sources. No blanket licence is assigned to the instructor
file, report identities or the entire project.

scientific evidence, report build dependencies and public instructions. The first

the executed-byte fingerprints of older experiments, some of which ran with local

success, a later Milestone update, final submission readiness or actual submission.
