[Reproduction](../docs/reproduction.md) supplies numerical, figure and report build
commands and their expected outputs. The historical reader tasks write PDFs
directly in each `-Output` directory beside `receipt.json`; no extra report
subdirectory is used. The current terminology Proposal has a separate standalone
entry and an explicit unverified new-environment boundary.

All frozen report source files, original PDFs, approved identities, build inputs,
generators/checkers and creation-time checks remain unchanged. A version README
may still say `pending` at creation; the dated review record supplies subsequent
acceptance. New PDFs need their own checks and viewing. This engineering candidate
does not designate a new report, a final grading version or actual course submission.

Historical predecessors remain where required by source hashes and generation
imports. Use this index and the [version map](../docs/version-map.md) for current
status instead of treating old progress sentences as new claims.
